# GPT + Codex 實戰：打造 MorPage 銷售台與專屬 AI Agent

這是一份 45 頁 HTML 投影片，供「AI Agent 行銷工作助理」課程使用。

## 內容

- Codex 下載、安裝與登入
- Codex 主畫面、模型、速度與權限說明
- MorPage SOP 腳本附加與內建瀏覽器操作
- MorPage 測試商品上架流程
- 儲存前人工確認與列表驗證
- 專屬 AI Agent 工作流發想

## 開啟方式

直接用瀏覽器開啟 `index.html`。

投影片快捷鍵：

- `ArrowRight` / `Space`：下一頁
- `ArrowLeft`：上一頁
- `Home`：回第一頁
- `End`：到最後一頁

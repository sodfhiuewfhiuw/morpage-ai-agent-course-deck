# Codex AI Agent 電腦工作助理實戰

這是一份 GitHub Pages HTML 投影片，供 40-60 歲、電腦基礎較弱的學員跟做 Codex AI Agent 實作課使用。

## 課程主軸

學生只記兩件事：

1. 先丟給 Codex 正確的檔案、資料夾路徑，或確認不用丟檔案。
2. 再輸入對應提示詞。

安全主軸：AI 可以代做流程，但不能代替你做風險決定。

## 基礎概念

課程使用「AI Agent 駕訓班」比喻：

- Agent：整台車，負責把任務跑完。
- LLM：引擎，決定理解與推理能力。
- Token：油箱容量，一次能載多少資料。
- Tool：車上的方向盤、輪胎、雨刷，例如檔案、Office、Chrome。
- Skill / SKILL.md：駕駛手冊或任務 SOP。
- Markdown / HTML：提示詞、SOP、講義常用的文字與網頁格式。
- 安全邊界：煞車，高風險動作先停。

## 內容

- Codex 下載、安裝、登入與主畫面介紹
- LLM、Agent、Token、Skill、Markdown、HTML 基礎概念
- 練習一：整理混亂資料夾
- 練習二：Excel 銷售月報變會報摘要
- 練習三：Excel 支出表做會計複核清單
- 練習四：Excel 學員名單整理
- 練習五：Word 主管摘要與 PPT 會報大綱
- 練習六：電腦問題排查與低風險檢查
- 手機連 Codex 觀念
- 練習七：C 槽安全清理假資料盤點

## 素材包

課堂素材在：

```text
materials/Codex課堂實作素材包/
```

素材包根目錄入口頁：

```text
第00步_先開我_AI Agent駕訓班.html
```

素材包採用七站式命名：

- `01_第01站_整理車庫_混亂資料夾`
- `02_第02站_會報導航_Excel銷售月報`
- `03_第03站_風險煞車_Excel會計複核`
- `04_第04站_路線規劃_學員名單`
- `05_第05站_連續駕駛_Word與PPT`
- `06_第06站_故障排查_電腦問題診斷`
- `07_第07站_安全煞車_C槽假資料`

每一站都有 `先開我_第XX站任務卡.html`，會直接告訴學生：

- 第 1 步：丟給 Codex 什麼
- 第 2 步：再輸入什麼提示詞
- 到站成果：做到什麼算完成
- 煞車提醒：哪些事不能自動做

## 截圖準備

原教案已經有 Codex 下載、安裝、登入與主畫面截圖，不需要重做。

新版只補 AI Agent 駕訓班素材包相關截圖。老師用清單在：

```text
materials/Codex課堂實作素材包/99_老師補充資料_不要給學生/老師用_新版截圖準備清單.html
```

不要準備固定的電腦排查結果或 C 槽清理結果，因為每位學生電腦狀態不同。課堂要教的是怎麼問 Agent、怎麼看風險、怎麼低風險處理。
